# PROTOTYPE: staff app shell (throwaway)

Answers the wayfinder ticket "App shell and multi-tab navigation prototype".
Three variants of the staff app shell on one route, switchable via `?variant=A|B|C`
or the floating bar at the bottom (arrow keys also cycle).

Run: `pnpm --dir apps/staff-shell-prototype dev` then open http://localhost:3000/prototype/shell

Not production code. No tests, no persistence, mock data only.
